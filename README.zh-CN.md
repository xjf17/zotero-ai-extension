# Zotero AI 助手

一款 Zotero 插件，借助 AI 帮助你阅读论文、查找引文、回答你在笔记中写下的问题。插件对接任何 OpenAI 兼容 API，默认推荐使用 [OpenRouter](https://openrouter.ai)，通过一个 API Key 即可使用众多 AI 模型。

兼容 Zotero 7、8、9。

## 安装插件

1. 从 [Releases](../../releases) 页面下载最新的 `.xpi` 文件。
2. 打开 Zotero。
3. 进入 **工具 → 插件**。
4. 将 `.xpi` 文件拖入插件窗口，或点击右上角齿轮图标选择 **从文件安装插件…**
5. 按提示重启 Zotero。

重启后，Zotero 右侧导航栏中会出现三个新图标按钮。

## 配置 API

插件通过 API 调用 AI 模型，使用前必须填写 API Key。

### 获取 OpenRouter API Key（推荐）

OpenRouter 是一个 AI 模型聚合服务，用一个 API Key 即可使用 GPT-5.6 Luna、Claude、Gemini、DeepSeek 等众多模型，按量计费，大多数请求费用极低。

1. 前往 [openrouter.ai](https://openrouter.ai)，注册免费账号。
2. 在控制台进入 **Keys** 页面，点击 **Create Key**。
3. 复制 Key，格式为 `sk-or-` 开头。

### 在 Zotero 中填写 API Key

1. 在 Zotero 中打开 **编辑 → 设置**（Windows/Linux）或 **Zotero → 设置**（macOS）。
2. 点击 **Zotero AI** 选项卡。
3. 将 API Key 粘贴到 **文本模型 API Key** 字段。
4. 将同一个 Key 也粘贴到 **Embedding 模型 API Key** 字段（引用查找功能需要）。
5. 点击 **保存设置**。

> 默认的 API 地址和预选模型开箱即用，无需修改其他任何设置。

## 功能使用

插件在 Zotero 右侧导航栏添加了三个图标按钮。所有功能也可以通过在文献库中右键点击条目，选择 **AI …** 菜单项来使用。

---

### 1. 读取论文

**功能说明：** 读取所选论文的 PDF 全文，生成结构化中文阅读笔记，自动保存为该论文的子笔记。

**使用方法：**

1. 在 Zotero PDF 阅读器中打开一篇论文，或在文献库中选中一篇带有 PDF 附件的文献。
2. 点击右侧导航栏中的 **读取论文** 按钮（文件图标）。
3. 进度提示出现，插件会提取 PDF 文字、发送给 AI 并保存结果。
4. 完成后，该论文下会出现一条新的子笔记，包含 AI 生成的阅读笔记。

**笔记内容包括：**
- 研究问题与目标
- 研究方法
- 主要发现与贡献
- 局限性与未来方向

**使用技巧：**
- 可以在 **设置 → 摘要最多片段数** 限制处理的文字块数量，以减少费用和等待时间。设为 `0` 表示处理全文。
- 默认会排除末尾几页（通常是参考文献列表）。可在 **设置 → 摘要排除末尾页数** 调整。
- 笔记开头会注明使用的模型名称，方便追溯。


---

### 2. 查找引用

**功能说明：** 在你的整个 Zotero 文献库中，用语义检索找出与你输入的想法或论点相关的论文，即使它们使用了不同的词语表述。

**使用方法：**

1. 点击右侧导航栏中的 **查找引用** 按钮（搜索图标）。
2. 搜索面板打开，输入你的想法或论点，例如：*"注意力机制提升了长文档任务的性能"*。
3. 点击 **搜索**。
4. 插件搜索本地文献索引，显示最相关的论文，附带简短理由和原文摘录。

**首次使用——建立索引：**

引用查找需要先对文献库建立本地向量索引。首次搜索时，插件会询问是否立即建立索引，点击 **确定** 后等待，数百篇文献的索引通常需要几分钟。

- 索引仅覆盖当前 Zotero 视图中可见的文献。切换到 **我的文献库** 可对全库建索引。
- 也可以在 **设置 → 重建当前视图索引** 手动重建。
- 在设置中更换 Embedding 模型后，旧索引会自动清除，并提示重新建立。

---

### 3. 回答笔记问题

**功能说明：** 读取 Zotero 笔记中写下的问题，结合所属论文的 PDF 全文作为上下文，在笔记中追加 AI 回答。

**使用方法：**

1. 打开一条附属于论文的 Zotero 子笔记。
2. 在笔记末尾用以下格式写下你的问题：
   ```
   Q: 这篇文章如何处理数据增强问题？
   ```

3. 保持笔记选中，点击右侧导航栏中的 **回答笔记问题** 按钮（问答图标）。
4. 插件读取父论文 PDF 和问题内容，在笔记中追加 `Answer:` 回答段落。

**使用技巧：**
- 一条笔记中可以有多组问答。插件每次只回答**最后一个**未回答的问题。
- 收到回答后，继续在笔记末尾写新的 `Q:` 即可继续提问。


---

### 4. 解释图表和公式

**功能说明：** 在 PDF 阅读器注释侧边栏的图片注释上，会出现一个小亮星按钮（✨）。点击后，插件将图片发送给多模态 AI 模型，并将解释写入注释评论中。

**使用方法：**

1. 在 Zotero PDF 阅读器中打开一篇论文。
2. 使用 **区域注释** 工具（矩形选框）框选一个图表、图形或公式区域。
3. 注释出现在右侧注释列表中，注释卡片右上角会显示一个小亮星图标（✨）。
4. 点击亮星图标。
5. AI 解释会写入该注释的评论字段，悬停或打开注释时可见。

**使用技巧：**
- 点击亮星按钮前，可以先在注释评论中写 `Q: 你的问题`，AI 会针对性地回答该问题，而非给出通用解释。
- 此功能使用 **多模态模型** 设置，默认为 Gemini 3.6 Flash。

## 高级设置

打开 Zotero 设置，点击 **Zotero AI** 选项卡，可访问所有配置选项。

### AI 模型选择

| 模型类型 | 默认值 | 用途 |
|---|---|---|
| 文本模型 | DeepSeek V4 Flash | 读取论文、引用重排、笔记问答 |
| 多模态模型 | Gemini 3.6 Flash | 图表/注释解释 |
| Embedding 模型 | Nemotron Embed 1B（免费）| 构建和搜索引用索引 |

从下拉菜单选择其他模型，或选择 **自定义 model id** 后手动输入你的 API 服务商支持的任意模型 ID。

### 使用其他 API 服务商

如果你有 OpenAI、Anthropic 或其他 OpenAI 兼容服务的 API Key：

1. 将对应模型类型的 **接口格式** 从 `OpenRouter` 改为 `OpenAI 兼容`。
2. 填写完整的 API 地址（例如 `https://api.openai.com/v1`）。
3. 填写 API Key。
4. 填写准确的模型 ID（例如 `gpt-4o`）。

### 索引设置

- **摘要最多片段数（0 = 不限制）：** 限制读取论文时发送的文字块数量，数值越小速度越快、费用越低。
- **摘要排除末尾页数：** 跳过每篇 PDF 末尾的页数（通常是参考文献列表），默认为 2。
- **引用结果数量：** 引用查找返回的结果数量，默认为 5。

### PDF 模式

- **本地文本优先（默认）：** 使用 Zotero 已索引的文字，速度快且免费。
- **远程 PDF parser/OCR fallback：** 若本地文字不可用（如扫描版 PDF），插件将 PDF 发送给远程 API 解析，消耗较多 token。

## 常见问题

**"请先选中一篇带 PDF 的文献"**
点击读取论文前，请先选中或打开一篇有 PDF 附件的 Zotero 条目。

**"没有找到未回答的问题"**
确认笔记末尾有 `Q:` 或 `问题:` 格式的问题，且下方没有已有的 `Answer:` 段落。

**查找引用没有结果**
索引可能为空或已过期。在搜索面板中确认重建提示，或前往设置点击 **重建当前视图索引**。

**API 报错 / "未填写 API Key"**
前往设置，确认对应模型类型的 API Key 字段已填写，并核对 API 地址是否与服务商匹配。

**注释上没有出现亮星按钮**
亮星按钮仅出现在图片/区域注释上，不会出现在文字高亮注释上。请使用区域选择工具框选图片区域来创建注释。

**更换 Embedding 模型后索引被清除**
这是正常行为——用一种模型构建的向量无法用另一种模型搜索。更换模型后需重新建立索引。
